# User Stories

1. **User Registration**: As a new user, I want to register with a username, email, and password so that I can create an account and access the app.
2. **User Login**: As a registered user, I want to log in with my email and password so that I can view my personalized data.
3. **Home Screen Navigation**: As a user, I want to view the home screen with a clear header and navigation options so that I can browse app sections easily.
4. **Item Detail View**: As a user, I want to open a detail screen for an item so that I can see full information about it.
5. **Local Data Persistence**: As a user, I want my data to be saved locally so that it remains available when I reopen the app.
6. **External API Data**: As a user, I want to view data fetched from an external API so that I can see live or external information in the app.
7. **Settings Menu Access**: As a user, I want to open the settings menu from a clear icon so that I can reach app configuration options.
8. **App Settings Configuration**: As a user, I want to adjust app settings on the settings screen so that the app behaves according to my preferences.
9. **Notifications Setup & Alerts**: As a user, I want to configure and receive notifications so that I get timely alerts from the app.
